100% RAM Processing & Zero Telemetry Guarantee

All operations in Atelier execute strictly inside your local browser instance via HTML5 APIs, Canvas, Web Workers, and the Web Cryptography API. Atelier does not transmit files, keys, tokens, or queries across any external servers.

Offline PWA Resilience

Equipped with a Service Worker (Cache-First strategy), all tool modules function completely offline once installed or cached.
